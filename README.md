# Counter App

Una semplice applicazione realizzata con **HTML**, **CSS** e **JavaScript** che permette di aumentare, diminuire e resettare un contatore.

L'obiettivo del progetto è mettere in pratica la manipolazione del DOM, la gestione degli eventi e l'utilizzo di JavaScript per creare un'applicazione interattiva.

---

## Linguaggi utilizzati

- HTML
- CSS
- JavaScript

---

## Funzionalità

- Aumento del contatore
- Diminuizione del contatore
- Reset del valore
- Aggiornamento dinamico del numero
- Interfaccia responsive
- Animazione del contatore
- Cambio colore del numero in base al valore

---

## Obiettivi del progetto

Questo progetto è stato realizzato per esercitarmi con:

- Manipolazione del DOM
- Event Listener
- Variabili e funzioni
- Condizioni (`if`)
- Classi CSS dinamiche
- Organizzazione del codice JavaScript
